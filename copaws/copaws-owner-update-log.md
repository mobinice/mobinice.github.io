## 固定更新流程

每次更新依照以下流程執行：

1. 以 Figma UI 稿作為畫面與元件的唯一基準。
2. 將已確認的 UI 與互動同步至 HTML 原型。
3. 檢查 UI 與原型內容、版面、文案及互動是否一致。
4. 以 428px × 939px 手機畫布驗證，並補充桌面滑鼠操作測試。
5. 將完成版本推送至 Git，確認 GitHub Pages 線上原型已更新。
6. 產出業主更新摘要，並在本文件新增日期、內容、版本與驗證結果。
